# Moro App - Deep Code Audit Report

## 1. EXECUTIVE SUMMARY

### What's Solid ✅
- **Navigation architecture**: Clean React Navigation setup with tab + stack structure
- **Context-based state management**: Well-organized providers for trading, social, news, auth, watchlist, theme
- **UI components**: Polished, themed components with dark/light mode support
- **Backend infrastructure**: Full AWS CDK stack with DynamoDB tables, Cognito, Lambda, API Gateway
- **Type system**: Comprehensive TypeScript types in `src/types/index.ts`

### What's Mock/Fake ⚠️
- **Entity data**: All entities come from `MOCK_ENTITIES` (40 hardcoded people/startups)
- **News**: Generated by `generateMockNews()` - no real news API integration
- **Social feed**: `MOCK_POSTS` used as fallback; posts don't persist without backend
- **Groups**: Fully mock with `MOCK_GROUPS`; backend not implemented
- **Trading without backend**: Uses local state; resets on app restart
- **Simulator**: Empty file (0 bytes)
- **Leaderboards/Seasonal Competition**: "Coming Soon" placeholder

### What Blocks MVP 🚫
1. **Backend deployment** - The backend exists but isn't deployed; app falls back to mock everywhere
2. **Persistence** - All trades, posts, follows reset without backend
3. **Real entity prices** - No market data source; prices are random
4. **Leaderboards** - Core competitive feature completely missing
5. **Categories infinite scroll** - Basic treemap exists; no infinite discovery feed

## 4. CODE-LEVEL FINDINGS

### 4.1 Trading System Correctness

**Buy/Sell Flow** (`TradeModal.tsx:97-134`)
- ✅ Input validation: quantity > 0, decimal handling
- ✅ Insufficient funds check: `hasSufficientFunds = totalCost <= portfolio.cashBalance`
- ✅ Insufficient shares check: `hasSufficientShares = quantityNum <= holding.quantity`
- ⚠️ No price staleness check - user could trade at outdated price
- ⚠️ No market hours concept

**Price Calculation** (`TradingContext.tsx:44-69`)
- Prices initialized with hardcoded ±3-5% moves from `basePrice`
- Capped at $80-$200 range
- No real price feed; relies on backend `/api/entities` which also returns mock prices

**Position Cost Basis** (`TradeModal.tsx:142-151`)
- Correctly calculates expected P&L for sells using `holding.averageCost`

**Persistence**
- ⚠️ `holdings` and `transactions` stored only in React state
- Backend polling every 5 seconds when authenticated (`TradingContext.tsx:183-192`)
- Without backend, all trades lost on app restart

### 4.2 Data Fetching + Caching

**API Wrapper** (`config/api.ts`)
- ✅ Timeout handling with AbortController (10 seconds)
- ✅ Graceful error handling for network failures
- ✅ Bearer token injection via `authenticatedRequest`
- ⚠️ No retry logic
- ⚠️ No request cancellation on unmount/navigation
- ⚠️ Entity news cache in `NewsContext` but no TTL

**Loading States**
- ✅ `isLoadingFeed`, `isLoadingNews`, `isLoading` flags present
- ✅ Skeleton/placeholder UI in some screens

### 4.3 Auth + Session Handling

**Token Storage** (`AuthContext.tsx:67-79`)
- Tokens stored in AsyncStorage (unencrypted)
- Refresh token stored separately

**Token Verification** (`AuthContext.tsx:40-65`)
- On app load, calls `verifyToken()` to validate saved token
- Falls back to logout if invalid

**Risks**
- ⚠️ AsyncStorage is unencrypted - tokens accessible on rooted devices
- ⚠️ `skipAuth` dev bypass present in production builds (WelcomeScreen:43-48)
- ⚠️ No automatic token refresh on 401

### 4.4 Social Objects

**Feed Pagination**

### 4.5 News + Sentiment

**Screen Performance**

### 4.7 Security + Privacy

🚨 **SECURITY ISSUES FOUND:**

1. **Hardcoded JWT Secret** (`backend/infrastructure/stack.ts:267`)
   ```typescript
   JWT_SECRET: process.env.JWT_SECRET || 'moro-oauth-secret-key-change-in-production'
   ```
   **Risk**: Default secret used if env var not set
   **Fix**: Make JWT_SECRET required, fail deployment if missing

2. **Dev Skip Auth in Production** (`WelcomeScreen.tsx:43-48`, `LoginScreen.tsx:269-275`)
   ```typescript
   <TouchableOpacity onPress={handleSkipAuth}>
     <Text>Skip</Text>
   </TouchableOpacity>
   ```
   **Risk**: Anyone can bypass authentication
   **Fix**: Guard with `__DEV__` check

3. **AsyncStorage for Tokens** (`AuthContext.tsx`)
   **Risk**: Tokens stored unencrypted
   **Fix**: Use `expo-secure-store` for sensitive data

4. **Console Logging** 
   - Debug logging throughout (`console.log`, `console.debug`)
   - **Fix**: Remove or guard with `__DEV__`

### 4.8 Type Safety

**Types** (`types/index.ts`)
- ✅ Comprehensive types for all entities
- ⚠️ No Zod/runtime validation for API responses
- ⚠️ `any` casts in API response mapping (e.g., `SocialContext.tsx:306`)

### 4.9 Testing + Build Health

- ❌ No test files found
- ❌ No ESLint/Prettier config visible
- ❌ No CI/CD configuration
- ❌ No error boundaries
- ❌ No crash reporting integration (Sentry, etc.)
